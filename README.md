# Pandas Sales Analyzer & Data Visualization

## About the Project

This is a simple Python project made to analyze sales data using Pandas and NumPy. It also uses Matplotlib and Seaborn to create different charts and graphs.

The project has a menu-driven interface, so users can select different options to explore data, perform calculations, handle missing values, and visualize sales information.

## Features

- Load sample sales data or a CSV file.
- Display the first and last five rows.
- Check column names, data types, and dataset information.
- Perform NumPy array operations.
- Search products and sort or filter sales data.
- Calculate total, average, and number of sales.
- Handle missing values.
- Calculate mean, median, variance, standard deviation, and percentiles.
- Combine and split DataFrames.
- Create pivot tables.
- Generate different charts using Matplotlib and Seaborn.
- Save charts as image files.
- Export data to a CSV file.

## Requirements

Make sure Python is installed on your computer.

Install the required libraries using the following command:

```bash
pip install pandas numpy matplotlib seaborn
```

## How to Run the Project

**Step 1:** Clone the repository.

```bash
git clone https://github.com/jayshah121005/Pandas_analyzer.git
```

**Step 2:** Open the project folder.

```bash
cd Pandas_analyzer
```

**Step 3:** Run the Python file.

```bash
python sales_analyzer.py
```

If your Python file has a different name, replace `sales_analyzer.py` with your actual filename.

**Step 4:** Select an option from the main menu.

Choose option 1 to load sample data, or enter the name of your CSV file when prompted.
